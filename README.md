# Portfolio

Personal portfolio of **K.M. Tousif Bin Parves** — AI & Robotics researcher.

🔗 **Live site:** [tousifo.github.io](https://tousifo.github.io)

A modern, fully responsive single-page portfolio built with plain HTML, CSS and JavaScript — no build step, no framework.

## Features

- 🌗 **Dark / light mode** with system-preference detection and `localStorage` persistence
- ⌨️ **Typing animation** (Typed.js) and scroll-reveal animations (AOS)
- 📌 Sticky glassmorphism navbar with active-section highlighting and scroll progress bar
- 📱 Fully responsive with a mobile hamburger menu
- 🗂️ Sections: About, Education, Experience timeline, Projects, Achievements, Volunteering, Tousif Lab resources, Contact
- ⚡ No dependencies to build — deploy anywhere static (GitHub Pages)

## Structure

```
index.html    # Main page
lab.html      # Tousif Lab — learning resources
styles.css    # Design system + all styles (light & dark themes)
scripts.js    # Theme toggle, nav, animations
assets/       # Images, CV, documents
```

## Development

Serve locally:

```bash
python3 -m http.server 8000
```

then open <http://localhost:8000>.
